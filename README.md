# Data Visualization: Airbnb Listings Analysis

## Task Description
This repository contains the Data Visualization for Descriptive Statistics. The  code and full analysis can be found in the file: `Data Visualisation.ipynb`. 

The goal is a deep analysis of the airbnb listings dataset. The analysis focuses on the relationships between accommodation types, prices, locations, guest ratings, and popularity.

---

## Visualizations Included
1. Distinct room type counts
2. Average price by room type
3. Price vs rating by room type
4. Histplot of logarithms of price counts for each room type
5. Price brackets counts for each room type
6. How diverse the room offers are in different districts
7. Distribution of Listing Ratings
8. Price Distribution by Room Type
9. Number of Reviews vs. Price

---

## Summary 
The visualizations reveal the following key insights about the short-term rental market:

1. **Privacy comes at a cost:** 
The dataset is heavily dominated by "Entire place" and "Private room" listings. Accommodations with no privacy "Shared rooms" make up a negligible fraction of the available accommodations and are the most affordable option. "Entire place" listings command the highest average price and variance.
2. **Geography determines the offering:** Location strongly influences the type of available listings. Manhattan is the primary hub for entire apartments, whereas Brooklyn dominates the private room segment.
3. **Price does not guarantee higher satisfaction:** There is no distinct correlation between a listing's price and its rating across all room types. Both budget-friendly and premium options frequently achieve similar scores, with the vast majority of ratings heavily concentrated between 4.0 and 5.0, regardless of the price point.
4. **Affordability result in popularity:** There is an inverse relationship between nightly price and the number of reviews. More affordable listings accumulate a significantly higher volume of reviews, indicating that cheaper options experience the highest guest count and booking frequency.
